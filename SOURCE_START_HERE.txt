UCPC — вихідний код, запуск як у розробника
Windows 11 x64

ПЕРШИЙ ЗАПУСК

1. Натисни на архів правою кнопкою → «Видобути все».
   Розпакуй у свою папку «Документи» та відкрий папку UCPC.
   Усі файли залиш разом. Запускати потрібно з розпакованої папки.

2. Один раз установи uv — він встановить потрібний Python і залежності.
   Якщо uv уже встановлений, переходь до кроку 3.

   Відкрий PowerShell або Термінал з меню «Пуск».
   Скопіюй цей рядок цілком, встав і натисни Enter:

   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

   Дочекайся закінчення, потім закрий це вікно.
   Це офіційний установник uv. Інструкція:
   https://docs.astral.sh/uv/getting-started/installation/

3. У папці UCPC двічі натисни SETUP.cmd.
   Потрібен інтернет. Перший раз встановлення може тривати кілька хвилин.
   Дочекайся напису «Setup complete» й натисни будь-яку клавішу.
   «ChatGPT: вхід потрібен» під час перевірки — нормальний стан перед входом.
   Цей крок створює папку .venv та стандартні налаштування.
   Python окремо ставити не потрібно: uv вибере Python 3.14.5 з .python-version.

4. Двічі натисни start.vbs. UCPC запускається у фоні без чорного вікна.
   При першому запуску відкриються налаштування.
   Вкладка «Акаунт» → «Увійти через ChatGPT» → увійди у СВІЙ акаунт у браузері.
   Повернися у програму, вибери доступну модель і натисни «Застосувати».
   Після цього Esc ховає налаштування.

НАСТУПНІ ЗАПУСКИ

Просто двічі натисни start.vbs. Установлення повторювати не потрібно.
Логотип UCPC знаходиться біля годинника, іноді під стрілкою ˄.
Повністю закрити: правою кнопкою на логотип → «Закрити UCPC».
Після перезапуску комп'ютера знову відкрий start.vbs.

ЯК КОРИСТУВАТИСЯ

Mouse4          додати скріншот; повтори для інших частин умови
Mouse5          відправити всі зібрані скріншоти разом
Ctrl+Win+F1     допомога з усіма актуальними біндами
Ctrl+Win+F11    показати / сховати відповідь
Ctrl+Win+F12    налаштування
Ctrl+Win+F7     скопіювати весь текст поточної відповіді
Ctrl+Win+F10    перевірити видимий результат після запуску коду
Ctrl+Win+F2     скасувати поточний запит
Ctrl+Win+F3     очистити чергу скріншотів
Ctrl+Win+PgUp/PgDn   прокрутити текст вгору / вниз
Ctrl+Win+Z/X    попередня / наступна відповідь
Ctrl+Win+G/J    посунути вікно ліворуч / праворуч
Ctrl+Win+Y/H    посунути вікно вгору / вниз
Ctrl+Win+U      повернути вікно в центр

Win — клавіша з логотипом Windows. На ноутбуці PgUp/PgDn іноді потребують Fn.
Якщо немає бокових кнопок, у налаштуваннях признач Ctrl+Win+F8 для скріна
та Ctrl+Win+F9 для відправки. Усі комбінації можна змінити.
Розмір вікна змінюється перетягуванням нижнього правого кута.
Білу / чорну тему вибирай на вкладці «Вигляд» та застосуй Ctrl+S.
Приховування вікна залишає запит працювати у фоні.
Перед використанням з OBS зроби короткий тестовий запис на своєму ПК.

ЯКЩО НЕ ЗАПУСКАЄТЬСЯ

• Спочатку дочекайся успішного закінчення SETUP.cmd.
• Якщо написано, що uv не знайдено, виконай крок 2, закрий Термінал
  і запусти SETUP.cmd ще раз.
• Якщо start.vbs просить setup.ps1, запусти SETUP.cmd.
• Якщо UCPC вже працює, знайди логотип біля годинника.
• Якщо Windows не запускає .vbs, відкрий Термінал саме в папці UCPC
  (правою кнопкою в порожньому місці → «Відкрити в Терміналі») і виконай:

  .\.venv\Scripts\python.exe -m ucpc

  Тоді вікно Термінала залиш відкритим, поки користуєшся програмою.
• Після переміщення всієї папки встанови залежності через SETUP.cmd ще раз.

ДЛЯ РЕДАГУВАННЯ КОДУ

Код програми — у папці ucpc. Його можна відкрити у Visual Studio Code.
Після зміни коду закрий UCPC через логотип і запусти start.vbs знову.
Після зміни залежностей потрібно оновити uv.lock через uv lock,
потім повторити SETUP.cmd. Звичайне користування цього не потребує.
Тести — у tests, інструменти перевірки та збірки — у tools.
Повна інструкція з командами та налаштуваннями — у README.md.

В архіві стандартні шаблони. Під час першого запуску з них створюються
config.toml, system_prompt.txt та порожній .env. Акаунт підключаєш сам.
Вхід зберігається для твого користувача Windows у %LOCALAPPDATA%\UCPC.
Паролі, токени, скріншоти, відповіді та налаштування розробника не включені.

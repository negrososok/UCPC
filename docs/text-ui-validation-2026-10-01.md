# Перевірка текстової версії UCPC 0.2 — 2026-10-01

## Результат

- 127 автоматичних перевірок: 0 помилок, 0 пропусків, попередження вважаються помилками.
- П’ять повторних стрес-циклів у нових процесах: усі пройшли після виправлення блокування файлу входу.
- Ruff: усі перевірки пройшли.
- Реальний запит із синтетичним білим зображенням: gpt-5.6-sol повернула `UCPC OK`; скріншот робочого столу не надсилався.
- Упакований UCPC.exe запускається в окремій папці з чистим LOCALAPPDATA, створює стандартні файли й завершує smoke-перевірку з кодом 0.
- Чиста папка дистрибутива перевірена; акаунт, ключі, особиста інструкція, історія, логи та робоча конфігурація до неї не копіювались.
- ZIP навмисно не створений: користувач просив архів після погодження версії.

## Захоплення

Для оверлею й налаштувань перевірено WDA_EXCLUDEFROMCAPTURE та реальне захоплення через MSS при непрозорості 75%, 94% і 100%. Під захищеним вікном показувалося синтетичне синє вікно; запис повертав саме його пікселі, а не чорний прямокутник. Окремо перевірено видиме popup-меню в треї. Оверлей при появі не забирав клавіатурний фокус. Відмова захисту залишала оверлей прихованим.

Конкретна сцена OBS цією серією тестів не керувалась. Роботу попереднього оверлею в OBS користувач підтвердив; на іншому ПК потрібний короткий пробний запис у його способі захоплення.

## Знайдено та виправлено під час перевірок

1. FileLock видаляв файл блокування після звільнення. Під одночасним навантаженням Windows інколи повертала Access denied іншому потоку. Увімкнено збереження стабільного файлу блокування; сама native-блокировка звільняється як раніше. Мінімальну версію filelock піднято до 3.30.
2. PATH середовища збирача містив сторонній Poppler. PyInstaller помилково копіював його ICU DLL замість використання сумісної системної ICU Windows. PATH збірки обмежено Windows і Python; холодний запуск чистого дистрибутива пройшов.
3. Локальні клавіші налаштувань могли перехоплювати запис бінда. Записувач приймає ShortcutOverride, щоб вибрана комбінація потрапляла до нього.

# Перевірка UCPC — 1 жовтня 2026

Повний набір: **112 тестів пройшли за 17,49 с**. П’ять додаткових прогонів у нових процесах: **10/10 тестів у кожному**, без попереджень, помилок чи зависань. Ruff перевірив код і форматування. Перевірки `--check`, `--voices`, `--devices`, `--smoke` завершилися успішно.

## Виправлення входу

Закриття вкладки не відправляє OAuth callback. Попередня версія чекала три хвилини й мовчки ігнорувала повторне натискання кнопки. Тепер повторний клік відкриває ту саму спробу, а «Скасувати вхід» дозволяє почати нову. Часті кліки не створюють зайві потоки чи вкладки.

Перевірено закриту вкладку без callback, скасування, нову спробу, відмову в дозволі, таймаут, збій браузера, неправильний/повторений state, пізні результати старої спроби та скасування під час обміну токенів. Локальні сервери перевіряються через справжні сокети; закриття listener перевіряється безпосередньо. Незавершений локальний HTTP-запит не блокує скасування.

Додатково виправлено перевірку NaN/Infinity і типів налаштувань, звільнення ресурсів після часткового запуску та збою аудіопристрою. Додано межі текстового й аудіобуфера та обмеження частоти захоплення. Захоплення переведено на актуальний конструктор установленої бібліотеки MSS після виявленого попередження про застарілий виклик.

## Збої та покриття

Справжній OpenAI SDK працював зі штучним HTTP transport: успіх у режимах API/підписки, 401/403/429/500/503, ConnectError, ReadTimeout, порожній і обірваний SSE. Перевірено відсутність автоматичних повторів, коректні параметри запиту, завершення треку й відсутність передачі скріншота при локальних помилках доступу. Збій TTS скасовує текстову генерацію навіть при заповненій черзі.

Покриття виконуваних рядків у повному прогоні — **84%**. Audio і capture — 100%, config — 99%, speech — 96%, engine — 95%, hotkeys — 92%, auth — 90%, app — 81%. CLI перевірявся окремими процесами й не входить у виміряне покриття. Відсоток показує виконані рядки, а не гарантію відсутності всіх помилок.

Трей, панель, реєстрація/доставка/звільнення хоткеїв, початок та завершення мережевого потоку перевірено на цьому Windows-комп’ютері. Наявні голоси SAPI — англійські David і Zira. Аудіоперевірки подавали тишу; вони не оцінюють якість української вимови.

## Межі перевірки та повторний запуск

Живий вхід OpenAI та відповідь на реальний скріншот потребують завершення входу користувачем. Ліміти акаунта не витрачалися. Не проводився стрес зовнішніх серверів, багатогодинний прогін або запис OBS. Налаштування джерел OBS і відсутність голосу в готовому записі слід перевірити окремим коротким записом.

```powershell
uv run pytest -q -W error
uv run python tools/repeat_stress.py --cycles 5
uv run ruff check .
uv run ruff format --check .
uv run python -m ucpc --check
uv run python -m ucpc --smoke
```

`--smoke` запускається при закритому основному екземплярі. Повторні стрес-прогони залишають локальні результати в `data/stress/summary.json`, `cycle-*.xml` і `cycle-*.txt`. Повний прогін із покриттям також створив `coverage.json` та `stress-results.xml`; ці діагностичні файли виключено з Git.

# UCPC — особистий текстовий помічник

UCPC працює у фоні. Збери один або кілька скріншотів, потім відправ їх моделі одним запитом. Відповідь з’явиться поверх екрана. Голосу немає. Скріншоти не зберігаються на диск: початкові кадри залишаються в оперативній пам’яті для окремої перевірки результату запуску. Усі відповіді залишаються в історії до закриття програми; обмеження їх кількості немає.

Готова програма для Windows і окремий архів із вихідним кодом доступні в
[GitHub Releases](https://github.com/negrososok/UCPC/releases/latest).
Для запуску без встановлення Python завантаж **UCPC-Windows11-x64-v0.2.0.zip**.
Для читання, редагування й запуску коду завантаж **UCPC-source-Windows11-v0.2.0.zip**.

## Запуск із вихідного коду

1. Видобудь **усі** файли архіву або клонуй цей репозиторій у звичайну папку.
2. Установи [uv](https://docs.astral.sh/uv/getting-started/installation/).
3. Запусти **SETUP.cmd** і дочекайся повідомлення **Setup complete**.
4. Запусти **start.vbs**. Наступного разу достатньо цього файла.

Python 3.14.5 вибирається через **.python-version**, залежності — через **uv.lock**.
Докладна інструкція: **SOURCE_START_HERE.txt**. Код знаходиться в **ucpc/**,
тести — у **tests/**, інструменти перевірки й пакування — у **tools/**.
Ліцензію для вихідного коду поки не додано.

## Запуск на іншому ПК: Windows 11, x64

Для готової збірки Python, uv і Visual Studio Code не потрібні.
Коротка інструкція звичайним текстом — **START_HERE.txt** поруч із UCPC.exe.

1. Скопіюй архів на інший ПК.
2. Натисни на архів правою кнопкою → **Видобути все**. Обери звичайну папку, наприклад `Документи\UCPC`. Не запускай програму прямо з архіву.
3. Відкрий отриману папку й двічі натисни **UCPC.exe**. Залиши поруч папку `_internal` та всі інші файли зі збірки.
4. При першому запуску з’являться налаштування. На вкладці **Акаунт** натисни **Увійти через ChatGPT**. Заверши вхід у браузері.
5. Повернись у UCPC. Залиш `gpt-5.6-sol` або натисни **Показати доступні моделі**, вибери модель і натисни **Застосувати**.
6. Закрий налаштування клавішею **Esc**. Відкрий потрібну задачу й натисни **Mouse4**. Прокрути сторінку й повтори для інших частин. Коли зібрав усі кадри, натисни **Mouse5**. Текст почне з’являтися автоматично.

Для режиму ChatGPT окремий API-ключ не потрібний. Інтернет і доступ акаунта до моделі потрібні. Вхід у браузері бачить лише OpenAI; пароль у UCPC не вводиться. Якщо випадково закрив вкладку входу — натисни кнопку входу ще раз. Якщо спроба завершилася помилкою, скасуй її та почни нову.

Коли прибираєш вікно, UCPC продовжує працювати. Логотип UCPC шукай біля годинника, іноді під стрілкою **˄**. Щоб повністю закрити програму: правою кнопкою на логотип UCPC → **Закрити UCPC**.

## Основні клавіші

Скріншоти та відправка за замовчуванням виконуються боковими кнопками Mouse4 і Mouse5. Для інших стандартних команд утримуй **Ctrl+Win** і натискай потрібну клавішу. **Win** — клавіша з логотипом Windows між Ctrl та Alt. Alt у стандартних біндах не використовується, тому натискати його для UCPC не потрібно. Літери — клавіші англійської розкладки; їхнє місце на клавіатурі не змінюється при перемиканні мови.

| Дія | Комбінація |
|---|---|
| Допомога: усі поточні бінди | **Ctrl+Win+F1** |
| Додати скріншот до запиту | Mouse4 |
| Відправити зібрані скріншоти | **Mouse5** |
| Перевірити видимий результат запуску | **Ctrl+Win+F10** |
| Очистити зібрані скріншоти | Ctrl+Win+F3 |
| Показати / сховати відповідь | Ctrl+Win+F11 |
| Відкрити / сховати налаштування | Ctrl+Win+F12 |
| Скасувати поточний запит | Ctrl+Win+F2 |
| Прокрутити вгору / вниз | Ctrl+Win+PageUp / PageDown |
| Прокрутити довгий код ліворуч / праворуч | Ctrl+Win+A / R |
| Попередня / наступна відповідь | Ctrl+Win+Z / X |
| Початок / кінець тексту | Ctrl+Win+Home / End |
| Зменшити / збільшити текст | Ctrl+Win+F5 / F6 |
| Повернути вікно в центр | Ctrl+Win+U |
| Скопіювати всю поточну відповідь | **Ctrl+Win+F7** |
| Посунути вікно вгору / вниз | **Ctrl+Win+Y / H** |
| Посунути вікно ліворуч / праворуч | **Ctrl+Win+G / J** |

На ноутбуці для F-клавіш іноді потрібно також утримувати **Fn**. Якщо PgUp/PgDn підписані на стрілках, використовуй Ctrl+Win+Fn зі відповідною стрілкою. Прокручування та переміщення можна виконувати утриманням комбінації. Зйомка кадру лише додає його до черги й не скасовує генерацію. Відправлення нового набору скасовує попередню незавершену генерацію; вже отриманий текст залишається в історії. Перемикання історії повертає до твого місця читання в кожній відповіді.

Кількість зібраних кадрів видно в захищеному вікні відповіді. **F3** з Ctrl+Win прибирає весь зібраний набір, не скасовуючи поточний запит. Після успішного відправлення черга очищується. Якщо звичайний запит завершився помилкою й нових кадрів немає, **Mouse5** повторить останній набір без повторної зйомки. Вхід і непорожня системна інструкція перевіряються перед відправленням; при локальній помилці кадри залишаються в черзі. Кадри передаються в порядку зйомки за [форматом кількох зображень OpenAI](https://developers.openai.com/api/docs/guides/images-vision).

**Ctrl+Win+F7** копіює весь текст вибраної відповіді, навіть коли вікно приховане. Виділення, прокручування й активне вікно не змінюються. Якщо відкрив попередню відповідь, копіюється саме вона. Поки модель генерує, копіюється весь уже отриманий текст на момент натискання. Якщо тексту ще немає, буфер обміну залишається без змін. Цей бінд також можна змінити на вкладці **Клавіші**.

Розмір вікна відповіді змінюй, потягнувши його нижній правий кут. Можна також перетягнути вікно за заголовок. Позиція та розмір запам’ятовуються; перемикання теми їх не скидає. **Ctrl+Win+G/Y/J/H** посувають вікно ліворуч/вгору/праворуч/вниз без мишки. Уяви стрілки на клавіатурі: Y над H, G ліворуч від H, J праворуч. Ці клавіші обрані з урахуванням стандартних біндів VS Code і Windows.

**Ctrl+Win+F1** відкриває або приховує допомогу з усіма поточними командами. Вона показує твої змінені комбінації та позначає вимкнені як «Не призначено». Після застосування налаштувань допомога оновлюється. Її вікно також виключене із захоплення. **Ctrl+Win+F11** та закриття вікна відповіді лише приховують текст: запит продовжується у фоні. Скасування виконується окремою командою **Ctrl+Win+F2**.

## Перевірити результат запуску

1. Збери повну умову через **Mouse4**, відправ через **Mouse5** та дочекайся завершення відповіді.
2. Скопіюй код через **Ctrl+Win+F7**, встав у редактор, скомпілюй і запусти на своєму тесті.
3. Залиш на екрані вхідні дані та фактичний результат або повідомлення компілятора. Натисни **Ctrl+Win+F10**.
4. UCPC зробить свіжий кадр і попросить модель зіставити його з початковою умовою та кодом саме вибраної відповіді. Перевірка з’явиться окремою сторінкою історії. Модель пояснить збіг, помилку або нестачу даних.

Програма сама не компілює код і не надсилає його на сайт. Для конструктивної задачі перевіряються властивості відповіді: правильний результат може відрізнятися від прикладу. Перевірка одного видимого тесту не означає проходження всіх тестів. Якщо перевірка завершилась помилкою, **Ctrl+Win+F10** повторює її зі свіжим кадром. Кадри, які ти вже збираєш для наступної задачі, залишаються в окремій черзі. Для звичайного нового запиту початкові кадри старих задач не додаються.

## Налаштувати під себе без мишки

1. Відкрий налаштування: **Ctrl+Win+F12**.
2. **Ctrl+1**, **Ctrl+2**, **Ctrl+3**, **Ctrl+4** перемикають вкладки: клавіші, вигляд, акаунт, інструкція.
3. **Tab** переходить до наступного елемента; **Shift+Tab** — до попереднього. **Space** або **Enter** натискають вибрану кнопку.
4. Щоб змінити бінд, перейди до його кнопки, натисни **Space**, потім свою комбінацію. **Esc** скасовує запис; **Backspace** під час запису прибирає бінд.
5. На вкладці **Вигляд** вибери **Біла** або **Чорна**. Тема застосовується до відповіді, допомоги та налаштувань після **Ctrl+S**.
6. **Ctrl+S** застосовує зміни. Якщо клавіша зайнята або повторюється, побачиш пояснення; попередні робочі налаштування збережуться.
7. **Esc** приховує налаштування. Зміни без застосування залишаються чернеткою до закриття UCPC.

Попередні стандартні бінди з Alt автоматично замінюються комбінаціями Ctrl+Win. Старі стандартні F2/F9/F10 також оновлюються під послідовність Mouse4 → Mouse5 → запуск коду → Ctrl+Win+F10. Стандартні F8/F9 мігрують на Mouse4/Mouse5; власні та вимкнені призначення зберігаються. Якщо власна комбінація займає новий стандартний бінд, відповідна стара комбінація залишається; за потреби вибери її самостійно.

Під час запису бінда глобальні клавіші UCPC тимчасово вимкнені; після запису вони повертаються. Якщо вимкнув бінд налаштувань, їх можна відкрити подвійним натисканням на логотип UCPC у треї або кнопкою у вікні відповіді.

Можна призначати бокові кнопки мишки **Mouse4 / Mouse5**. Натисни кнопку бінда, потім потрібну бокову кнопку: окремо або разом із Ctrl або Shift. Натисни **Ctrl+S**, щоб застосувати. Стандартно Mouse4 — додати скрін, Mouse5 — відправити. Якщо бокових кнопок немає, запиши Ctrl+Win+F8 для скріна та Ctrl+Win+F9 для відправки. Призначена комбінація працює у фоні й поглинається UCPC, тому одночасно не перемикає сторінку браузера. Непризначені комбінації працюють звичайно. F1 показує актуальні призначення. Якщо драйвер мишки перетворює бокову кнопку на клавішу, записуватиметься ця клавіша.

Для задач програмування мова береться з умови або редактора; якщо її не видно — C++23. Інструкція просить простий зрозумілий код без зайвих абстракцій, але з потрібним алгоритмом для лімітів задачі. Відступи показуються й копіюються без втрат: таб дорівнює чотирьом пробілам у вікні. У завершеному впізнаному коді C/C++, Java, C#, JavaScript, TypeScript, Go та Rust звичайні відступи по чотири пробіли приводяться до табів; вміст рядків і коментарів зберігається. У впізнаному правильному Python блоки приводяться до чотирьох пробілів. Програма звіряє синтаксичне дерево до й після зміни; якщо змінилася структура або код має некоректні змішані відступи, оригінал зберігається. Вміст багаторядкових рядків захищений. Невпізнаний текст зберігається без змін. Промпт містить конкретні правила й короткі приклади простого стилю кількома мовами; власний парсер вводу потрібен лише коли цього вимагають ліміти. Ці вимоги до стилю не гарантують правильність розв'язання.

На вкладці **Інструкція** можна змінити те, як модель відповідає. Зміни діятимуть для наступного запиту. За замовчуванням для задач із програмування модель проситься повернути лише код. На вкладці **Акаунт** повзунок **Рівень аналізу** змінюється стрілками після переходу Tab. `medium` — збалансований режим, `high` — ретельний; стандартний рівень лишається `high`. Нижчий рівень може дати відповідь швидше, але потребує перевірки на твоїх задачах. Натисни **Ctrl+S**, щоб застосувати до наступного запиту. Номер монітора змінюється на цій самій вкладці. `1` — перший монітор, `0` — усі монітори.

## OBS

UCPC просить Windows виключити вікно відповіді, налаштування, допомогу та меню в треї із захоплення. Якщо Windows не підтвердила виключення, вікно з текстом не показується. На поточному ПК це перевірено реальним захопленням екрана; користувач також підтвердив роботу в OBS.

На іншому ПК перед використанням зроби короткий тестовий запис у своїй сцені OBS: відкрий відповідь, налаштування й допомогу та подивись запис. Результат залежить від способу захоплення. Звичайний браузер для входу в ChatGPT не приховується UCPC. Перед власним скріншотом UCPC також тимчасово прибирає свої вікна, щоб вони не потрапили до моделі.

## Якщо щось не працює

- **Після зміни акаунта написано «Цей обліковий запис не має доступу до цього застосунку» / `3p_login_workspace_scope_denied`:** відкрий вкладку **Акаунт** і натисни **Інший акаунт / робочий простір**. Це почне нове підключення для потрібного акаунта. У браузері вибери саме свій акаунт із підпискою та потрібний робочий простір. Стара кнопка входу повторно входить у збережене підключення, яке прив'язане до попереднього акаунта й workspace. Підключення різних акаунтів зберігаються окремо; після додавання іншого їх можна вибирати у списку на цій вкладці та натискати кнопку входу. Невдалий або скасований новий вхід не стирає чинний акаунт. Якщо відмова повторюється навіть при новому підключенні з правильним акаунтом, збережи код помилки та ID запиту зі сторінки OpenAI для підтримки. Не пересилай посилання входу чи токени.
- **Немає вікна:** натисни Ctrl+Win+F11 або відкрий логотип UCPC. Центр вікна відновлює Ctrl+Win+U.
- **Клавіша зайнята:** налаштування відкриються з поясненням. Признач іншу комбінацію та застосуй. Типові бінди перевірені проти стандартних Windows-біндів VS Code; власні бінди й установлені розширення можуть додавати свої.
- **Модель недоступна:** на вкладці Акаунт натисни Показати доступні моделі, вибери модель та застосуй.
- **Немає доступу або закінчилися ліміти:** перевір вхід і натисни Перевірити ліміти в браузері.
- **Невірний монітор:** встанови правильний номер на вкладці Акаунт.
- **Не зберігаються налаштування:** перемісти всю папку UCPC у свою папку Документи. У захищених системних папках запис може бути недоступний.
- **Другий запуск:** UCPC дозволяє один екземпляр для одного користувача Windows. Знайди вже запущений логотип UCPC.
- **Відповідь довго не приходить:** у захищеному вікні видно етап та час очікування. Один прохід має до 10 хвилин на генерацію; якщо текст почав надходити наприкінці цього часу, він отримує щонайменше 3 хвилини на завершення. Таймер продовжується лише при першому тексті: нескінченні службові події або потік символів не можуть тримати запит вічно. Мережеве очікування без жодних байтів — до 3 хвилин; встановлення з’єднання — до 15 секунд. Для двох проходів бюджет надається кожному окремо. Отриманий при помилці текст позначається неповним. При помилці Mouse5 повторює останні скріни, якщо нових ще не знімав. Перший новий скрін скидає старий набір для повтору. Автоматичного повторного відправлення немає.

Автоматична подвійна перевірка **за замовчуванням вимкнена**: звичайна відповідь приходить одним запитом, а результат запуску перевіряється окремо через **Ctrl+Win+F10**. На вкладці **Акаунт** можна увімкнути «Перевіряти відповідь перед показом». Тоді UCPC робить два запити: чернетку та перевірку за оригінальними скрінами; показує лише завершений результат другого проходу. Це повільніше й використовує більше ліміту акаунта. Окрема перевірка результату завжди виконується одним запитом. Для моделей із підтримкою міркування стандартний `reasoning_effort` — `high`; його можна змінити повзунком у вкладці **Акаунт** або в `config.toml`.

Перевірка просить модель шукати помилки алгоритму, крайові випадки та контрприклади. Вона не компілює і не запускає код, не навчає ваги моделі та не гарантує правильну відповідь. Знімай повну умову, обмеження й приклади. Кожен новий відправлений набір створює окремий запит: стара історія, відповіді та скріни до нього не додаються. Кілька кадрів до натискання відправки є частинами одного запиту. Нове відправлення скасовує попередню незавершену генерацію.

Журнал запитів: `%LOCALAPPDATA%\UCPC\requests.log`. Щоб знайти його, натисни Win+R, введи `%LOCALAPPDATA%\UCPC` та Enter. Журнал містить UTC-час, ідентифікатор запиту, етапи, модель, кількість кадрів, тривалість, кількість символів та тип/HTTP-код помилки. Скріншоти, текст відповідей, інструкції, токени входу й ключі в нього не записуються. Зберігаються основний файл до 1 МБ та три попередні файли. Етап `answer` означає нову задачу, `verification` — перевірку результату. Токен входу завчасно оновлюється перед кожним проходом; при явній помилці `token_expired` до появи тексту виконується одне оновлення і повтор цього проходу. Для помилок ліміту чи доступу автоматичного повтору немає. Для завершених запитів також записуються кількості вхідних, вихідних та reasoning-токенів; зміст міркувань не записується. `generation_timeout` у `config.toml` задає час одного проходу (стандартно 600 с), `request_timeout` — мережеве очікування між байтами (180 с). Ліміт історії прибрано; ліміти доступу та використання сервісу залишаються чинними.

Програма запам’ятовує позицію вікна й вхід у `%LOCALAPPDATA%\UCPC`. Токени входу захищені Windows для твого користувача. На інший ПК їх переносити не потрібно: увійди заново. Налаштування й інструкція створюються поруч із UCPC.exe після першого запуску. Чиста збірка містить лише стандартні шаблони, без акаунта, ключів, історії та особистої інструкції.

Для задач із програмування додаткові інструкції вимагають враховувати найгіршу складність, вкладені цикли, кількість переходів DP, сумарну роботу всіх тестів та ліміт пам'яті. У режимі перевірки **Ctrl+Win+F10** модель окремо розглядає перевищення часу й повідомлення судді. Це загальні вимоги до розв'язання, а не вбудовані відповіді на окремі задачі. Якщо `high` думає надто довго, можна вибрати `medium` у налаштуваннях і повторити запит. Жоден рівень не гарантує правильний результат: запускай код і перевіряй різні входи.

## Розробка: тести та збірка

Цей розділ потрібний для роботи з вихідним кодом.

Установи [uv](https://docs.astral.sh/uv/getting-started/installation/). У PowerShell у папці проєкту виконай:

```powershell
uv sync --locked
.\.venv\Scripts\python.exe -m ucpc --check
```

Для звичайного запуску двічі натисни **start.vbs**. Для запуску з повідомленнями в терміналі:

```powershell
uv run python -m ucpc
```

Перевірки та збірка:

```powershell
uv run pytest -q -W error
uv run ruff check ucpc tools tests
uv run python -m tools.audit_shortcuts
uv run python -m tools.repeat_stress --full-cycles 2 --cycles 10
uv run --group build python -m tools.build_release
```

Остання команда готує папку `dist\UCPC` без архівування. Архівування виконується окремо після погодження версії. Збірник копіює тільки явно перелічені модулі та стандартні шаблони; робочі `.env`, `config.toml`, `system_prompt.txt`, `data` та профіль входу не копіюються. Windows-збірку потрібно будувати на Windows. Для API-режиму доступні `auth_mode="api"`, `api_vision_model` та власний `OPENAI_API_KEY` у створеному `.env`; цей режим має окрему оплату.

Повторні тести запускаються в нових процесах і зберігають звіти у `data/stress`. Вони використовують синтетичні дані та підмінений мережевий сервіс, а перевірки Windows — справжні події вводу й тестові вікна. Під час цих перевірок бажано не користуватися мишею та клавіатурою: вони тимчасово керують фокусом тестового вікна.

Для окремої перевірки стилю на справжній моделі: `uv run python -m tools.evaluate_style`. Вона надсилає чотири синтетичні зображення задач, використовує ліміт поточного акаунта, зберігає відповіді в `data/style-eval` і запускає їх на 20 тестах. Для всіх чотирьох мов потрібні g++, Python, Node.js та .NET 8 SDK. Ця команда запускається вручну; звичайний UCPC не компілює й не виконує отриманий код.

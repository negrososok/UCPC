# Стандартні бінди без Alt — 2026-10-01

Після повідомлення про підкреслення меню VS Code всі 19 стандартних біндів UCPC переведено на один префікс Ctrl+Win. Кожна комбінація має три клавіші. Міграція розпізнає обидва попередні набори стандартних біндів, зберігає власні та вимкнені комбінації й не займає власний бінд новим стандартним.

Підбір враховує стандартні комбінації Windows та спеціальних можливостей. Наприклад, Ctrl+Win+D/стрілки належать віртуальним робочим столам, Ctrl+Win+L — живим субтитрам, Ctrl+Win+Q — Quick Assist. На цьому ПК Ctrl+Win+E також виявилася недоступною при RegisterHotKey; для горизонтального прокручування обрано A/R. Рух вікна: Y вгору, H вниз, G ліворуч, J праворуч. Джерела: [Windows](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows), [спеціальні можливості](https://support.microsoft.com/en-us/accessibility/windows/windows-keyboard-shortcuts-for-accessibility), [живі субтитри](https://support.microsoft.com/en-us/accessibility/windows/use-live-captions-to-better-understand-audio).

Перевірки:

- 141 тест пройшов за 47,41 с; попередження трактуються як помилки. Доказ: data/no-alt-tests.xml.
- Native SendInput активує кожен із 19 біндів у власному синтетичному редакторі. Обидва порядки натискання модифікаторів перевірені. Alt не натиснуто; редактор зберігає текст і фокус, меню «Пуск» не забирає фокус. Тест реєструє лише callback і не виконує скріншотів або запитів до моделі.
- Міграція обох старих наборів, власні/вимкнені бінди й колізії з новим стандартним біндом перевірені.
- Ruff пройшов. Конфліктів із 1261 правилом Microsoft, числовими правилами встановленого VS Code 1.140.0 та 92 правилами вбудованих розширень не знайдено. Доказ: data/shortcut-audit.json. Власні бінди VS Code та сторонні розширення можуть відрізнятися.
- Запуск вихідної версії після міграції: всі 19 біндів зареєстровано, Alt відсутній, вибрана користувачем чорна тема збережена.
- Чиста EXE-збірка з новим logo/logo.png запущена з окремим LOCALAPPDATA у папці з пробілами й українськими літерами. Код завершення 0; шаблон містить 19 біндів без Alt; старе лого та облікові дані відсутні. Доказ: data/portable-no-alt-check.json.

Саме відображення меню у VS Code після оновлення цією серією не захоплювалося. Native-тести підтверджують, що стандартні комбінації UCPC взагалі не посилають Alt і не змінюють текст/фокус тестового редактора. Налаштування VS Code не редагувалися.

README та шаблон конфігурації оновлено. Програму перезапущено. ZIP залишається окремим кроком після погодження користувача.

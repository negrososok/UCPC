# Біла/чорна тема і коротші бінди — перевірка 2026-10-01

Ця перевірка стосується оновлення після текстової версії 0.2.

- `pytest -q -W error`: 138 перевірок пройшли за 37,37 с; стресові сценарії включено до цієї серії.
- Ruff: без зауважень. Синтетичні попередні перегляди білої/чорної відповіді й спрощеної вкладки «Вигляд» оглянуто.
- Реальний MSS-захват: обидві теми відповіді та налаштувань при 75%, 94%, 100% непрозорості. Отримано пікселі синтетичного тла під вікном, без вмісту UCPC чи чорного прямокутника.
- Застосування чорної теми зберігає геометрію, яку вибрано перетягуванням, та підтверджене WDA_EXCLUDEFROMCAPTURE.
- Чотири нативні WM_HOTKEY пересувають відповідь рівно на заданий крок у кожному напрямку. На цьому ПК усі 19 коротших стандартних комбінацій успішно зареєстровано через RegisterHotKey.
- Міграція попередніх стандартних біндів перевірена окремо. Власні та вимкнені бінди зберігаються; нова стандартна комбінація не замінює стару, якщо її вже займає власний бінд.
- VS Code: 1261 правило повного Windows-списку Microsoft, числові правила встановлених 1.124.2 / 1.139.1 / 1.140.0 і 198 правил їхніх вбудованих розширень. Для 19 нових стандартних біндів конфліктів не знайдено; кожен має три клавіші. Власні бінди VS Code та сторонні розширення можуть відрізнятися.
- Лого включено в трей, іконку вікон та EXE. Аудит дистрибутива дозволяє тільки конкретний logo/logo.png і перевіряє його вміст; сторонній PNG відхиляється тестом.
- Зібрано чисту папку dist/UCPC з 215 файлами разом із маніфестом. Власна конфігурація, інструкція, облікові дані, історія й логи не копіюються.
- Холодний запуск копії EXE у папці з пробілами й українськими літерами та чистим LOCALAPPDATA: код 0, стандартні файли створено, модель gpt-5.6-sol, світла тема, правильне лого, файл облікових даних відсутній. Доказ: data/portable-theme-check.json.

Сам OBS у цій серії не керувався. Перевірено Windows-захоплення; попередню роботу в OBS підтвердив користувач. Новий запит до моделі не виконувався: модель і мережевий протокол у цьому оновленні не змінювалися.

README оновлено. ZIP буде створено після погодження цієї версії, як просив користувач.

На прохання користувача лого замінено на logo/logo.png, старий logo/image.png видалено з папки лого. Після заміни Ruff і п’ять перевірок збірки пройшли; окремий тест підтверджує відхилення старого PNG у дистрибутиві.
